=====================================================
  PulseGuard — 아주 쉬운 설명
=====================================================

■ 이게 뭔가요?
  기존에 만들었던 "시스템 감시 프로그램"을, 다른 사람에게 매달 구독료를
  받고 팔 수 있는 정식 제품으로 다시 만든 것입니다.

■ 무료 vs Pro, 정확히 뭐가 다른가요?
  무료(평생 무료, 인터넷 필요 없음):
    - CPU/메모리/디스크 상태 확인 + 로컬 로그 기록
    - 위험 상황 시 이 PC 화면에 바로 알림 표시
    - http://localhost:8765 접속하면 실시간 상태를 볼 수 있는 화면
      (이 컴퓨터에서만 열리고 외부에서는 절대 접속 불가)
  Pro(월 2,900원 구독):
    - 무료 기능 전부 + 내가 자리에 없어도 디스코드/슬랙으로 알림 수신
    - 그동안의 기록을 CSV 파일로 내보내기
    - 로그를 더 오래(약 2주치) 보관

■ 어떻게 돈을 버나요?
  PixelBatch(사진 수정 사이트)에서 이미 실제로 작동하고 있는 방식을
  그대로 재사용했습니다.
    무료: 기본 감시 기능 (계속 무료)
    Pro(월 2,900원): 위험 상황 알림 + 기록 내보내기 등 추가 기능
  구매자가 Gumroad에서 결제하면 라이선스 키를 받고, 그 키를 프로그램에
  입력하면 Pro 기능이 켜집니다. 이건 이미 PixelBatch에서 실제로 팔리고
  있는 방식과 완전히 동일한 구조라 새로 검증할 필요 없이 바로 씁니다.

■ 제가(Claude) 이미 한 것
  - 프로그램 코드 작성 완료 (Windows/Mac/Linux 다 작동)
  - 소개 웹페이지 작성 완료
  - 개인정보처리방침 작성 완료
  - 검색엔진 노출용 설정 완료
  - 다른 3개 사이트에서 이 페이지로 연결되는 링크 추가 예정 (홍보)

■ 사용자님만 하실 수 있는 것 (계정 관련이라 대신 할 수 없음)
  1. Gumroad(이미 PixelBatch로 계정 있음)에 새 상품 만들기
     - 상품명: PulseGuard Pro
     - 종류: "구독형(Subscription)" 선택 — 월 2,900원 정도로 설정
     - URL 뒷부분(permalink)을 "pulseguard-pro"로 설정
     (permalink를 다르게 하고 싶으시면 말씀해주세요 — 코드에서 그 값으로 맞춰드립니다)
  2. GitHub에 저장소 만들고 이 폴더 업로드 (제가 도와드릴 수 있음 — SSH
     키만 한 번 더 등록해주시면 나머지는 제가 올려드립니다)
  3. GitHub Pages 켜기 (기존 PixelBatch와 똑같은 방법)

■ 솔직하게 말씀드릴 것
  프로그램과 웹페이지를 아무리 잘 만들어도, "구독자가 실제로 생기는 것"은
  보장할 수 없습니다. 비슷한 무료 프로그램(작업 관리자 등)이 이미 많아서
  경쟁이 있습니다. 다만 이미 만들어두신 3개 사이트와 서로 연결해서
  최소한의 노출은 만들어뒀습니다 — 나머지는 실제 사용 후기나 커뮤니티
  공유가 쌓여야 늘어나는 영역입니다.

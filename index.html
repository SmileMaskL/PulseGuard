🛡️ PulseGuard
저사양 PC 전용 설계

PC가 멈추기 전에,
조용히 지켜보는 프로그램

오래된 데스크탑·노트북의 CPU·메모리·디스크 상태를 평소엔 거의 아무 자원도 안 쓰면서 감시하다가, 문제가 생기기 전에 알려드립니다.

왜 필요한가요?

  • 디스크가 꽉 차서 갑자기 프로그램이 멈추는 걸 미리 방지
  • 메모리 부족으로 느려지는 원인을 로그로 남겨 추적 가능
  • 감시 프로그램 자체가 무겁다면 의미가 없다는 원칙으로 설계 — 평소 메모리 사용량 10MB 미만
  • 인터넷 연결 없이도 기본 기능(로컬 로그)은 완전히 동작

Pro

Pro 구독하기

구독은 매달 자동 결제되며, 해지하면 결제한 달까지는 Pro 기능을 계속 쓰고 다음 달부터 무료로 전환됩니다. 무료 기능은 구독 여부와 상관없이 평생 그대로 사용할 수 있습니다.

설치 방법

  1. Python이 설치되어 있어야 합니다 (없다면 python.org에서 무료 설치)
  2. GitHub 저장소에서 내려받기
  3. python pulseguard.py 실행 — 바로 무료 감시 시작
  4. Pro 구독 후 받은 라이선스 키로 python pulseguard.py activate 키값 실행하면 Pro 기능 활성화

Windows 작업 스케줄러나 Linux systemd에 등록하면 컴퓨터 켤 때마다 자동으로 조용히 실행되도록 만들 수 있습니다. 평소엔 거의 자원을 쓰지 않기 때문에 저사양 PC에서도 안심하고 켜두셔도 됩니다.

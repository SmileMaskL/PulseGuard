🛡️ PulseGuard
저사양 PC 전용 설계

PC가 멈추기 전에,
조용히 지켜보는 프로그램

오래된 데스크탑·노트북의 CPU·메모리·디스크 상태를 평소엔 거의 아무 자원도 안 쓰면서 감시하다가, 문제가 생기기 전에 알려드립니다.

왜 필요한가요?

  • 디스크가 꽉 차서 갑자기 프로그램이 멈추는 걸 미리 방지
  • 메모리 부족으로 느려지는 원인을 로그로 남겨 추적 가능
  • 감시 프로그램 자체가 무겁다면 의미가 없다는 원칙으로 설계 — 평소 메모리 사용량 10MB 미만
  • 인터넷 연결 없이도 기본 기능(로컬 로그)은 완전히 동작

설치 방법

Windows를 쓰신다면 아래 버튼 하나로 끝입니다 — Python을 몰라도 됩니다.

⬇ PulseGuard.exe 다운로드 (Windows용, 8MB)

다운로드한 PulseGuard.exe를 더블클릭하면 바로 실행됩니다. "Windows의 PC 보호" 경고가 뜨면 "추가 정보 → 실행"을 눌러주세요(서명되지 않은 개인 개발자 프로그램이라 뜨는 정상적인 안내입니다). Pro 구독 후 받은 라이선스 키는 실행 창에서 PulseGuard.exe activate 키값으로 입력하면 됩니다.

Mac/Linux를 쓰시거나 직접 소스코드로 실행하고 싶다면
  1. Python 설치 (없다면 python.org에서 무료 설치)
  2. GitHub 저장소에서 pulseguard.py 내려받기
  3. python pulseguard.py 실행

작업 스케줄러(Windows)나 systemd(Linux)에 등록하면 컴퓨터 켤 때마다 자동으로 조용히 실행되도록 만들 수 있습니다. 평소엔 거의 자원을 쓰지 않기 때문에 저사양 PC에서도 안심하고 켜두셔도 됩니다.

📘 오래된 PC가 느려지고 멈추는 이유와 점검법

몇 년 쓴 컴퓨터가 갑자기 버벅이거나 멈추는 원인은 대부분 몇 가지로 좁혀집니다. PulseGuard가 감시하는 항목도 바로 이 원인들입니다. 프로그램이 없어도 아래 방법으로 직접 점검해 볼 수 있습니다.

1. 디스크(C드라이브) 공간 부족

Windows는 업데이트 파일, 임시 파일, 가상 메모리(페이지 파일)를 C드라이브에 씁니다. 여유 공간이 거의 없으면 프로그램이 저장에 실패하거나, 업데이트가 멈추거나, 전체가 극도로 느려집니다. 일반적으로 전체 용량의 10~15% 이상은 비워 두는 것이 안전합니다.

  • 설정 → 시스템 → 저장소에서 "임시 파일"을 정리합니다.
  • "디스크 정리"(시작 메뉴에서 검색) → "시스템 파일 정리"로 이전 업데이트 파일을 지웁니다.
  • 다운로드 폴더와 바탕화면의 큰 동영상·설치 파일을 외장 저장장치로 옮깁니다.

2. 메모리(RAM) 부족

메모리가 가득 차면 Windows는 디스크를 메모리처럼 쓰기 시작하는데, 디스크는 메모리보다 훨씬 느려서 마우스까지 끊기는 현상이 생깁니다. 4GB 이하 메모리의 PC에서 인터넷 탭을 수십 개 열어 두면 흔히 발생합니다.

  • Ctrl + Shift + Esc로 작업 관리자를 열고 "메모리" 열을 눌러 많이 쓰는 프로그램을 확인합니다.
  • 쓰지 않는 브라우저 탭을 닫고, 브라우저의 "메모리 절약" 기능을 켭니다.
  • 작업 관리자 → "시작 앱" 탭에서 부팅 때 자동 실행될 필요 없는 프로그램을 "사용 안 함"으로 바꿉니다.

3. CPU 사용률이 계속 100%

아무것도 안 하는데 CPU가 계속 높다면 백그라운드 업데이트, 백신 검사, 또는 원치 않는 프로그램이 원인일 수 있습니다. 작업 관리자에서 CPU를 많이 쓰는 항목의 이름을 확인하고, 모르는 프로그램이라면 이름으로 검색해 정체를 확인하세요. 업데이트나 검사라면 끝날 때까지 기다리면 정상으로 돌아옵니다.

4. 열과 먼지

노트북 바닥의 통풍구나 데스크탑 팬에 먼지가 쌓이면 CPU가 과열을 막으려고 스스로 속도를 낮춥니다. 팬 소리가 유난히 크고 본체가 뜨겁다면 통풍구 청소만으로도 속도가 돌아오는 경우가 많습니다. 노트북은 이불·쿠션 위가 아닌 딱딱한 평면에 두고 쓰세요.

왜 "미리" 알아야 하나요?

디스크가 가득 차는 것, 메모리가 서서히 새는 것(메모리 누수)은 어느 날 갑자기가 아니라 며칠에 걸쳐 진행됩니다. 하지만 사용자는 멈춘 뒤에야 알게 되죠. PulseGuard는 60초마다 이 수치를 가볍게 기록해 두고, 위험 수준에 가까워지면 미리 알려 줍니다. 기록이 남아 있으니 "언제부터 느려졌는지"도 나중에 확인할 수 있습니다.

자주 묻는 질문

Q. 감시 프로그램 때문에 오히려 더 느려지지 않나요?

PulseGuard는 저사양 PC를 기준으로 설계되어 평소 메모리 사용량이 10MB 미만이며, 1분에 한 번 짧게 확인한 뒤 바로 쉬는 방식으로 동작합니다. 브라우저 탭 하나보다 훨씬 적은 자원을 씁니다.

Q. 백신 프로그램이 경고를 띄워요.

개인 개발자가 만든 서명되지 않은 실행 파일은 백신이나 Windows가 "알 수 없는 프로그램"으로 경고할 수 있습니다. 불안하다면 GitHub에 공개된 소스코드를 확인하거나, Python으로 소스코드를 직접 실행할 수 있습니다.

Q. 내 PC 정보가 외부로 전송되나요?

기본 기능은 인터넷 연결 없이 내 PC 안에서만 동작하며 기록도 내 PC에만 저장됩니다. Pro의 디스코드·슬랙 알림을 직접 설정한 경우에만, 사용자가 등록한 주소로 경고 문구가 전송됩니다. 자세한 내용은 개인정보처리방침을 확인하세요.

Q. Windows 7/8에서도 되나요?

배포용 .exe는 최신 Windows(10/11)를 기준으로 만들어졌습니다. 오래된 운영체제에서는 Python을 설치한 뒤 소스코드로 실행하는 방법을 권장합니다.
